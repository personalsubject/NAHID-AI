# NAHID AI

NAHID AI is an Android voice assistant prototype.

## Features

- Bengali speech recognition
- Hey Nahid wake phrase detection
- YouTube search
- Alarm intent
- Contact search and calling

## Build APK

1. Open the GitHub repository.
2. Go to Actions.
3. Select Build NAHID AI APK.
4. Select Run workflow.
5. Wait for the workflow to finish.
6. Open the completed workflow.
7. Download the NAHID-AI-APK artifact.

## Important

This is an early prototype. Continuous wake-word detection depends on
Android speech recognition, network availability, battery settings,
and device restrictions.

The app requires user-granted permissions for microphone, contacts,
and calling.
